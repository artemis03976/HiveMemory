# v0.7.3 版本收尾审计

本记录冻结 2026-11-04 的版本范围、版本目标判定、收尾分支的改动、遗留事项与验证结果。核对基线为 master `0adad62f`（v0.7.2 标签之后的 PR #157–#178），加上收尾分支 `release/v0.7.3` 的升版、文档收尾与一处 E2E 辅助函数的修正。当前实现从[项目总览](../../PROJECT.md)进入，生成链路的当前事实见 [Patchouli 生成](../../patchouli/generation.md)。

v0.7.3 内容收尾完成，Python 规范版本、运行时版本与前端包版本统一为 `0.7.3`。发布标签定为 `v0.7.3`，合并后创建；本次没有创建 tag，也没有发布产物。下文的“通过”只指所列的验证边界。

## 1. 版本目标与判定

版本目标（owner，2026-11-03）：主动写入与被动提取的收敛，作为过渡措施。DeepSeek Harness 接入后，经它调研的四个仓库是第一批以主动写入为主的真实样本：被动提取复现并改写了主动写入，同一轮里 agent 有意分开写的记忆被查重合并，主动写入的标题在生成时被丢弃，合并失败只能凭时序推断原因。owner 决定在想到更好的记忆生成策略之前先做这一组最小优化；它不代表主动写入优先是更好的选择，之后的方向见[统一的交互记忆](../../ideas/unified-interaction-memory.md)。证据、离线回放与决定见已归档的[收敛 Idea](../ideas/generation-source-convergence.md)。

三份计划都以离线回放验收；日常使用中的实测依赖自然发生的结算、写入与失败，不作为归档条件（各计划第 8.3 节）。

本机常驻后端在 PR #176 合并后以当时的代码重启，此后没有再重启：日志中有话题内主动写入优先的丢弃记录，同时还保留着 PR #177 删除的控制器失败日志。下表的真实样本都来自这份代码，PR #177、#178 的改动在常驻后端上还没有生效。

| 验收 | 判定 | 依据 |
|:---|:---|:---|
| 被动草稿不再改写本话题的主动写入 | 达成，有真实结算样本 | 离线：[话题内主动写入优先](./v0.7.3-topic-active-write-precedence.md)第 11 节，五个话题的 28 条被动草稿丢弃 24 条，保留的 4 条中 2 条低于相似下限、2 条命中还原条件之外的记忆。真实：2026-11-04 owner 经 dsh 重建 Gliding Horse 调研记忆，这个话题的 7 条主动写入落库后，结算提取出 7 条被动草稿，全部以 SIMILAR（0.779～0.858）命中本话题写入结算到的记忆而丢弃，没有新建，也没有提名合并。同一仓库 2026-11-02 的调研中，4 条被动草稿有 3 条并入了主动写入（收敛 Idea 第 2.2 节） |

## 7. 保留限制

- 本机常驻后端仍运行 PR #176 时的代码，`/health` 返回 `0.7.2`：生成失败的原因码与主动写入沿用标题都还没有生效，合并后需要以本版本代码重启。dsh 插件中的使用手册 skill 副本需要 owner 重新复制。
- 话题内主动写入优先是过渡措施，已知的缺口写在 [Patchouli 生成](../../patchouli/generation.md#8-当前限制)第 8 节：
  - 记录只在进程内，进程崩溃后的结算退回不区分来源的查重；
  - 结算开始时仍在执行的同话题写入不在记录中；
  - 复述写入但相似度不高于下限的被动草稿照常新建；
  - 话题落位错误时，另一段对话中与这些写入相似的草稿也会被丢弃；
  - 被动草稿里比主动写入更细的内容随草稿一起丢弃。
- 跨话题的合并不受影响：同一次结算的两条草稿命中同一条更早的记忆时，后写回的合并仍会失败并留下重复，收尾前真实出现过一次（[合并版本冲突 Todo](../../todo/merge-version-conflict.md)）。
- 多条提取之后被动提取的记忆膨胀明显、留存率低，记忆库靠 owner 手动清理（[被动提取膨胀 Todo](../../todo/passive-extraction-volume-and-retention.md)）。
- 三份计划的回放样本都来自 dsh 的四个调研仓库与 Claude Code 开发 HiveMemory 的会话，结论能否推广到其他领域未知。
- 任务进程表、会话与压缩检查点、写入意图登记、读取视图缓存、WorkspaceAsset working set、本地 Work Queue 与本话题主动写入的记录仍是进程内状态，不承诺跨重启恢复。
- 浏览器界面没有人工验收。
- 开发库中留有真实使用与验收写入的记忆、话题与交互 Artifact。
