# v0.6.2 版本收尾审计

本记录冻结 2026-09-14 的版本内容、归档承接与验证结果。核对基线为 `06cb75d5`（已包含 PR #94–#98）及本次文档归档、版本号调整。当前实现说明从 [项目总览](../../PROJECT.md) 和各模块事实文档进入，后续开发顺序从 [ROADMAP](../../ROADMAP.md) 进入。

v0.6.2 内容收尾完成，Python 规范版本、运行时版本及前端包版本统一为 `0.6.2`。本次发布标签确定为 `v0.6.2`，实际 Git tag 由合并后创建；本次没有创建 commit 或 tag，也未对外发布产物。下文的“通过”只指明列出的验证边界，不代表真实外部服务、浏览器或生产数据环境已经重新验收。

## 5. 保留限制与后续边界

- WorkspaceAsset/ref/lease、派生缓存与本地 Work Queue 仍是进程内状态，不承诺跨重启恢复。持久化 Memory/Artifact 与这些运行态的保证不同。
- 附件限 TXT、Markdown、DOCX，解析为受控同步执行，协作式预算不等于进程级硬超时或安全沙箱；DOCX 正文提取不承诺版式还原。
- 附件 promotion 是 CREATE/UPDATE 中的 best-effort 证据生成；ref 失效或 Store 关闭时可跳过并记录 warning，不回滚已提交结果。
- Profile cache 无失效事件/TTL，atom cache 返回 MemoryAtom 引用等限制继续由 ADR-0004 与当前文档说明。
- 本次未运行真实 LLM、Qdrant 等外部设施测试、`tests/e2e`、slow 测试或浏览器人工验收，也未对现有用户数据重新执行迁移。前端 bundle 体积提示不阻断本次构建。
- Workspace 资源体系与可替换 Actor 的边界重构仍为 [v0.7.0 计划](../../plans/v0.7.0-workspace-resource-system-and-agent-execution-boundaries.md)；外部 harness 接入、冷启动/历史导入、外源文档摄入、READ 特殊编译、Deep Research 与桌面交付按 ROADMAP 推进，不计入 v0.6.2 已交付能力。
