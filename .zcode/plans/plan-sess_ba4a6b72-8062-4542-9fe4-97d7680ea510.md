# A2-P 记忆内容版本与 Lifecycle 重构实施计划（含时间边界）

依据 `docs/plans/v0.7.0-a2-pre-memory-version-and-lifecycle.md`（MVL-0~4）与 `v0.7.0-time-semantics-and-controllable-clock.md`（execution: embedded-in-parent-plan，附录 A 已冻结字段清单）。共 6 个阶段，每阶段完成后做 code review（本人自审 + 独立只读代理核查）并停止汇报，等你确认再进入下一阶段。

## MVL-0：边界冻结（纯文档，不碰生产代码）

把以下冻结结论写入 A2-P 计划文档的 MVL-0 章节（时间附录 A 一并并入）：

- **逐字段 mutation 分类与写入者清单**：基于已核实的证据（updated_at 写点：engine.py:328/351/399、memory_generation.py:139、reinforcement.py:161、mid_term 整颗写回；lifecycle 写点：reinforcement.py:125-130、mid_term.py:113-114、engine.py:55；内容/版本：engine.py:353、memory_generation.py:140、artifacts/memory.py:99）。
- **置信度/验证状态规则（沿用现状，由 A2-P §3.1 授权）**：CREATE=draft 置信度（fallback 草稿 1.0）；UPDATE=重置 1.0；NEG 反馈=×0.5；`verification_status` 无写入方、恒 UNVERIFIED，迁入 lifecycle 后保持此规则。
- **失败传播**：按 A2-P §5.3 表逐条落为代码契约（artifact 失败→不发布 canonical；canonical 失败→传播并保留孤立 Artifact；不重试不补偿）。
- **兼容表**：Memory schema 整数 `2` 在临时迁移前只读（内容修订与 lifecycle patch 对旧记录直接拒绝）；MemoryVersionArtifact/MemoryCreationArtifact 旧 schema `"1"` 永远只读原样；InteractionArtifact/DocumentArtifact 布局不变（仅时间值转 UTC），schema 保持 `"1"`。
- **补充决定**：① `MemoryVersionArtifact` 与 `MemoryCreationArtifact` 都升 schema `"2"`（结构化 provenance + 完整快照）；② TOUCH（内容相同的重复访问）从"改 updated_at + 整颗 upsert"改为 lifecycle patch（access_count+1、last_accessed_at=now，不推进 decay_anchor_at、不动 updated_at、不升版本）；③ 旧 schema 只读的统一拒绝点放在 adapter `get_for_mutation` 与 `patch_payload` 的存储侧 schema 检查；④ 无既有策略更新调用方（access_policy 仅创建时设置），MVL-2 只交付 `patch_payload` 对 `meta.access_policy` 的白名单支持；⑤ 删除/归档/复活的同步协作点复用 `workspace/projections.py` 的 `CanonicalResourceChange` 形状，以可注入回调实现，无缓存配置时默认 no-op。

完成门槛：models/codec/formatter 单元测试绿；新格式往返（含嵌套 lifecycle/provenance/agent_config）不丢失；旧 schema 解码为只读形状、冲突拒绝；naive 输入被拒。

## MVL-2：受控 mutation 与 Familiar/Lifecycle 取时（时间计划 MVL-2 嵌入）

- **Port 层**（ports.py/stores.py/adapters/mid_term.py/vector_store.py）：`upsert(memory, *, recompute_vectors=True)`；新增 `patch_payload(key, patch) -> MemoryAtom | None`（dotted 白名单：7 个 `meta.lifecycle.*` 字段 + `meta.access_policy`，未知路径/类型错误/Workspace 不匹配/旧 schema 拒绝）；删除 `update_access_info`（生产调用方仅 retrieval.py:377 且 `update_access_stats` 无生产上游）。vector_store 实现真 `recompute_vectors=False`（取回既有向量原样复用，替换整份 payload，修复现存活参数）；patch 用 Qdrant `set_payload` 局部更新（向量不动）。store 层 patch/upsert 转发 primary+secondary 并传播错误。
- **引擎**（generation/engine.py）：`_apply_update`/TOUCH/`_draft_to_memory` 不再写 `meta.version/updated_at/session_id`，只做内容/index 合并、置信度草稿与 `memory_before_snapshot`；删除 history_summary 追加（:337-338）；`## 更新 (YYYY-MM-DD)` 日期改用 Familiar 传入的提交 now（:299-301）。
- **Familiar**（patchouli/services/memory_generation.py）：CREATE/UPDATE/外部写入路径入口一次 `current = require_utc(self._now())`；由 `memory_before_snapshot` 判定 embedding 输入是否变化决定 `recompute_vectors`；发布前赋值 version/updated_at/decay_anchor_at/created_at；artifact builder 与 MemoryEventLog.at 全部接收同一 now；TOUCH 决策改走 `patch_payload`；**移除 `_build_creation_artifacts`/`_build_update_artifact` 的捕获后继续提交分支（:490-495、:519-524）**——builder 失败直接传播，不发布 canonical；`build_for_create/build_for_update` 签名增加显式 `now`。
- **Lifecycle**（reinforcement.py、lifecycle/engine.py、services/lifecycle.py、garbage_collector.py、library.py）：reinforce 各事件改"读当前原子 → 纯计算 → `patch_payload`"（CITATION 推进 last_accessed_at+decay_anchor_at+加成；HIT 只推进 last_accessed_at+计数+加成；NEG 改 confidence；全部重算 vitality 后一并 patch，不改 version/updated_at、不写 Artifact、不重算向量）；`refresh_vitality(_batch)` 改 patch；`MemoryLibrary.revive` 改 `upsert(recompute_vectors=True)`；ArchiveRecord 时间用注入 now；MEMORY_DELETE/归档/复活路径挂同步协作点。
- **同步协作点**：Familiar 内容写入后、每次 patch_payload 成功后、删除/归档/复活成功后发布 `CanonicalResourceChange` 形状的变更描述给注入的回调列表；默认空列表 no-op。
完成门槛：HIT/CITATION/TOUCH/评分/反馈只改授权字段且不产生版本/向量重写（unit 可用 fake port 断言 patch 字段集）；agent_config-only 更新走 `recompute_vectors=False`；无并发/重试协议新增。

## 已知影响与风险（按计划接受，非缺陷）

1. 兼容窗口内（临时脚本执行前）旧 schema 记忆只读：内容修订与 lifecycle patch 对它们拒绝，本地开发 Qdrant 旧数据需在 A2-P 验收后运行临时脚本才能恢复可写。

3. e2e fixture（meta.session_id 必检）与 41 处 naive 测试时间将在 MVL-1b 一并修正；e2e 默认不跑，但保持契约一致。
4. `update_access_stats` 现无生产上游，本次仅将其实现迁到 patch_payload，不新增调用。
